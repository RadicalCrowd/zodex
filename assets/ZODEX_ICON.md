# Zodex Icon

`zodex-source.png` is the original high-resolution generated artwork.
`zodex.png` is the 256×256 production asset used by Linux packages.

The icon was generated with OpenAI's built-in image generation tool on
2026-08-16 specifically for this project. It does not use or reproduce the
OpenAI knot or Codex mark.

Prompt summary:

> Create a polished Linux coding-assistant icon using an abstract geometric
> Z-shaped routing path, angular cyan and violet ribbons, three connection
> nodes, a dark graphite rounded-square tile, and a small amber accent. Keep it
> readable at 32 px, with no words, robot face, watermark, OpenAI knot, or Codex
> logo.

The production PNG was downscaled from 1254×1254 with ImageMagick's Lanczos
filter. Both files retain an alpha channel and transparent corners.
